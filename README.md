# Ganesh Katam — portfolio & studio

A responsive personal portfolio and product studio for showcasing websites and applications, accessible at [tomesphere.in](https://tomesphere.in). Includes a lightweight studio dashboard for managing projects and profile details.

## Run locally

Install Node.js 20.19+ or 22.12+, then from this directory run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Make it yours

- Open **Dashboard → Projects** to add, edit, or remove website listings.
- Open **Dashboard → Settings** to change the sample name, bio, location, email, and social links.
- Dashboard and portfolio data is saved in this browser using local storage. For a public launch, replace browser storage with a database and add administrator authentication.

The initial entries and portfolio details are illustrative placeholders, not claims about the site owner's actual projects.
